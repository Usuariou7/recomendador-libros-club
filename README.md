# recomendador-libros-club
## 1. Qué es
Este proyecto recomienda libros de autores latinoamericanos, según el ánimo que ingresa el usuario.

## 2. Para quién
Está pensado para estudiantes o personas que desean descubrir una lectura según cómo se sienten.

## 3. Cómo se usa
1. Ejecuta el programa.
2. Escribe un ánimo (por ejemplo: Humor o Aventura).
3. El programa recomienda un libro.

## 4. Cómo se ejecuta

Opción A: Abrir el archivo en Google Colab
Opción B: Ejecutar localmente con Python 3:

```bash
python recomendador.py
```

## 5. Cómo se construyó con IA
- Se utilizó un chat de IA como asistente de escritura bajo dirección humana.
- Ciclo de construcción: Primero se creó una función mínima.
- Después se probó el caso límite terror.
- Rechacé una versión que ordenaba los libros por popularidad porque mi club valora la diversidad, no las modas.


## 6. Limitaciones
- El catálogo contiene pocos libros.
- Solo reconoce los estados de ánimo registrados.
- No recomienda libros personalizados.

## 7. Qué aprendí
- Lo más difícil fue probar con estados que no están registrados.
- Si empezara de cero agregaría un listado de libros para que haya más opciones para los estudiantes.
- Con dos semanas más colocaría una pequeña descripción de cada libro seleccionado.
